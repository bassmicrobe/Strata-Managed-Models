# Strata モデル切替版

公式Strataの安定版に、追加済みのローカルモデルとAPIモデルをチャットから切り替える機能を追加したforkです。Windows用インストーラーの標準構成では、専用の設定ファイルは不要です。既存の専用起動スクリプトを使う構成に限り、設定ファイルで管理するローカルモデル一覧も使えます。

`managed-models` がこのforkの管理ブランチです。上流は [Niko1221/Strata](https://github.com/Niko1221/Strata) です。上流の安定版を毎時確認し、新しい版を取り込んでから型チェック、画面ビルド、モデル切替のテストを実行します。合格した版だけが、このforkのReleasesに公開されます。競合や検証エラーがあれば公開を止め、最後に合格したリリースを残します。

## Windows用インストーラー

WindowsではRust/Tauriの専用ウィンドウを使います。ホストの起動・モデル管理・更新は引き続き同じStrataホストが担当します。インストーラーはWebView2が必要な場合だけMicrosoftのランタイムを導入します。

[Releases](https://github.com/bassmicrobe/Strata-Managed-Models/releases/latest) のWindows x64セットアップEXEを使います。NodeとControlを同梱し、モデル未設定で起動します。ユーザーが追加したローカルモデルとAPIモデルが切替一覧に反映されます。[日本語の使い方](windows-installer/README.ja.md) を同梱しています。

## PCで使うとき

起動時にWindowsインストーラーの版も比較し、検証済みの新版があれば更新を案内します。更新を選ぶと照合済みのセットアップを開きます。手動確認は専用ウィンドウの **Strata → 更新を確認** です。

PCの起動ファイルは、このforkの合格済みリリースを確認します。新しい版は別フォルダーで準備し、保存済みのモデル接続とチャットを使えることを起動確認してから切り替えます。回答やモデル読み込みの途中なら、更新を次回の起動へ回します。

推論エンジンとControlの更新は、公式Strataの署名付き配布に従います。インストーラーの標準構成では、モデルごとの設定をPC側に保存します。既存の専用3モデル環境では、32K・1チャットの調整値と画像リーダーなどの補助ファイルを引き継ぎます。

このリポジトリと配布ZIPに、モデル本体、APIキー、会話履歴、PCごとの実行パスは含めません。インストーラーの標準構成は、画面からモデルとAPI接続を追加して使えます。既存の専用起動スクリプトを使う構成では、必要に応じてSTRATA_MANAGED_MODELS_CONFIGを設定します。

## Tailscale共有（任意）

標準ではPC内だけで動きます。Tailscaleを実行PCと接続側の端末へ別途導入し、同じTailnetへ参加したうえで、スタートメニューの **Tailscaleで共有** を選びます。専用ウィンドウの **Strata → 共有URLをコピー** で取得したHTTPSの `ts.net` URLを、ポート番号も含めて使います。接続側はブラウザーだけでStrataを使え、モデルは実行PCで動きます。

共有設定は次の起動にも引き継ぎます。**Tailscale共有を停止** でPC内だけの利用へ戻します。既存のServe設定は上書きせず、利用できる共有ポートがなければ処理を止めます。Funnelによる公開は行いません。

共有する画面は、実行PCと同じ設定・会話履歴・モデル操作を使います。ユーザー別アカウントや操作権限は設けていません。接続者はTailnetのアクセス権で管理してください。[詳しい手順](windows-installer/README.ja.md#tailscaleで他の端末から使う任意) を参照してください。

## 配布物

- Windows用セットアップEXE: Node、Control、起動アプリ、日本語READMEを同梱。

- `managed-host-windows-x64.zip`: Nodeホスト、画面のビルド、ソース、テスト、組み込み識別ファイル。
- `managed-host.json`: forkと上流のコミット、対象機能、ZIPとインストーラーのサイズ・SHA-256。

リリース名の `managed-v0.2.12-1` は、上流0.2.12を基にした切替版のビルドを表します。アプリ内では上流のバージョン番号を使います。

CIはGPUを持たない環境でコードと起動経路を検証します。推論の速度や回答品質を保証するものではありません。

## 管理

Actionsの「Managed model updates」から手動実行できます。通常は自動確認に任せます。上流の同じタグが別コミットに変更された場合は自動で取り込まず、確認を求めるエラーにします。公開済みのタグやリリースは上書きしません。
